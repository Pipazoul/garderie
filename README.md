# garderie
A sandbox for llm agents to play with


## Agent Quicksart
```
use curl to request http://localhost:8050/llm.txt 
explain in french to user in simple terms what you as an agent can do with it and ask him what he wants to build with you
```

example credentials :
HOST: localhost          
PORT: 8050           
SSH_PASSWORD: pass      
PB_ADMIN_EMAIL: user@example.com  
PB_ADMIN_PASSWORD:  pass
NGINX_PORT: 80 (internal nginx listening port, useful when running multiple containers in the same pod)
PB_PORT: 8090 (internal PocketBase listening port)
WEBDAV_PORT: 8889 (internal WebDAV listening port)
